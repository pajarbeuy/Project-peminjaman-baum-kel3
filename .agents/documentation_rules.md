# Documentation Rules

- Gunakan Bahasa Indonesia yang jelas untuk dokumen akademik/proyek, kecuali kode, identifier, atau istilah teknis yang lazim.
- Pertahankan ID requirement, nama status, nama role, dan terminologi resmi dari SRS.
- Jangan menyatakan keputusan yang masih TBD sebagai keputusan final.
- Cantumkan sumber/versi dokumen dan tanggal jika benar-benar tersedia.
- Saat kebutuhan berubah, perbarui dokumen yang terdampak dan catat alasan perubahan.
- API berubah → perbarui Swagger dan contoh request/response.
- Skema data berubah → perbarui migration, ERD/data dictionary bila ada.
- Alur bisnis/status berubah → perbarui business_rules, tes, UI state, dan dokumentasi.
- Project plan/backlog/jadwal berubah → sinkronkan artefak terkait dan jelaskan delta.
- Hindari duplikasi aturan yang bertentangan. Jika aturan perlu diulang, rujuk sumber kanonik.
